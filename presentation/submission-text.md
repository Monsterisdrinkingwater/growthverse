# GrowthVerse · 成长宇宙 — Hackathon 提交文案

---

## 一句话介绍

AI 多 Agent 驱动的沉浸式阅读成长平台

---

## 详细描述（200 字以内）

GrowthVerse 是一款以读书为核心引擎的 AI 个人成长平台。5 个角色化 Agent（编排器、读书教练、社交分析师、反思伙伴、成长洞察师）覆盖“找书→探索→社交→反思→成长”的体验闭环。图书宇宙支持沿同作者、同主题、同时代递归探索；小红书与 B 站连接器在配置后聚合读者声音，未配置时明确降级为示例数据；三层反思把阅读触动沉淀到六大成长维度。技术栈：Next.js 15 + AI SDK 7 + Zustand/localStorage + 双源图书 API。

---

## 创新亮点

1. **图书宇宙递归探索** — 独创 Book Universe 交互范式，从一本书沿同作者/同主题/同时代三条维度递归展开，探索路径实时可视化为冒险地图，彻底颠覆传统"推荐列表"模式
2. **社交阅读数据融合** — 将小红书笔记 + B 站视频评论放进同一阅读体验，连接数据源后可对照两种社区视角
3. **AI 多 Agent 协作架构** — 5 位专门化 Agent 各司其职，通过 Tool-Use 模式实时调用外部 API（图书搜索、社交数据），不是"一个 AI 做所有事"，而是每个领域做到极致
4. **三层反思成长引擎** — 感知层→关联层→行动层的递进式反思引导，结果自动映射到六大成长维度（自我认知/情商/职业/关系/健康/哲学），让成长可量化、可追溯
5. **优雅降级策略** — 外部 API 不可用时自动降级为 mock 数据，保证所有功能在任何环境下完整可用

---

## 技术亮点

1. **Vercel AI SDK 7 + StreamText + Tool-Use** — AI 回复流式传输，工具调用实时可见，书名自动渲染为可点击卡片
2. **双源图书数据聚合** — 豆瓣读书 + Google Books 并行搜索，智能去重，自动回退
3. **Next.js 15 App Router** — Server Components + Streaming + 9 个 API 端点，全栈 TypeScript
4. **本地优先持久化** — 探索、反思、测验与设置保存在浏览器；仓库同时提供 12 表 Supabase 迁移作为后续扩展基础
5. **Zustand 5 状态管理** — 4 个轻量 Store 管理全局状态，高性能客户端渲染

---

## 使用场景

- **个人阅读成长**：AI 陪伴阅读、推荐适配、反思引导，帮助建立持续阅读习惯
- **知识探索发现**：图书宇宙递归探索，从一本书出发发现整个知识网络
- **社交阅读连接**：连接数据源后查看跨平台书评和讨论；无凭据时仍可用示例数据演示
- **成长可视化追踪**：六维成长地图 + 探索路径时间线，让阅读成长清晰可见
- **每日阅读仪式**：盲盒 + 测验等轻量互动，培养每日阅读习惯
