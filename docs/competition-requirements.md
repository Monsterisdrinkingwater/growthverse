## 三、作品提交要求

### 3.1 提交方式

通过 **WeaveFox 统一接口** 提交，官网：https://hackathon2026.app.weavefox.cn

提交流程：
1. 在**任一合作平台**完成作品开发
2. 在 WeaveFox 平台提交作品信息
3. **同步在小红书发布作品笔记**（带指定话题）

### 3.2 必须提交的内容

| 内容 | 说明 | 备注 |
|:----|:----|:----:|
| 📄 **项目说明文档** | 作品功能、使用方式、技术选型等 | 建议 Markdown 格式 |
| 🎥 **演示视频** | 展示作品核心功能和使用流程 | 格式不限，≤500MB |
| 💻 **源代码**（如有） | 完整可运行的源码或 Demo 链接 | AI辅助生成需注明 |
| 🖼️ **作品封面图** | 展示在作品广场的代表性图片 | 建议 16:9 或 1:1 |
| 📝 **作品描述** | 简短的作品说明文字 | 展示在作品卡片上 |
| 🔧 **搭建平台** | 使用的 AI Coding 平台/工具 | 如 Qoder、Codex、Kimi Code 等 |

### 3.3 提交格式限制

- 单个文件不超过 **500MB**
- 所有提交内容必须为**原创**，严禁抄袭
- 需在 WeaveFox 平台填写：作品描述、搭建平台、作品链接

### 3.4 小红书发布要求

| 项目 | 内容 |
|:----|:------|
| 平台 | 小红书 |
| 必带话题 | `#外滩大会全民黑客松` `#外滩大会AICoding大赛` |
| 发布内容 | 作品展示笔记（截图/视频+文字说明） |

## 四、参赛资格

| 条件 | 说明 |
|:----|:------|
| 国籍 | 遵守中华人民共和国相关法律法规的个人或团队 |
| 团队人数 | **1-5 人**，鼓励跨学科背景组队 |
| 年龄 | 年满 **18 周岁**，或取得监护人书面同意 |
| 限制 | 每位参赛者只能加入一个参赛团队 |

### 有效参赛定义

- ✅ 完成全部报名信息填写并通过身份核验
- ✅ 在规定时间内成功提交完整作品
- ✅ 提交的作品符合赛道主题要求
- ✅ 团队成员未违反参赛诚信声明
- ✅ 主动配合主办方进行的审核和验证工作

### 不合格作品判定

- ❌ 作品涉嫌抄袭、剽窃或侵犯他人知识产权
- ❌ 作品违反国家法律法规或社会公序良俗
- ❌ 提交不完整或无法在指定环境运行
- ❌ 作品与报名赛道主题完全不符
- ❌ 团队存在虚假报名、冒名顶替等违规行为
- ❌ 超过规定时间提交或未按要求格式提交
- ❌ 作品含有恶意代码或安全隐患

## 五、评审标准

### 5.1 专业评审

评审团：行业专家、技术大咖、产品经理

| 维度 | 权重 | 评审关注点 |
|:----|:----:|:----------|
| 💡 **技术创新性** | **40%** | 技术方案的新颖程度、AI 运用深度 |
| ✅ **项目完整度** | **30%** | 功能完备、可运行、交互体验 |
| 📈 **商业潜力** | **20%** | 痛点洞察、方案有效性、推广潜力 |
| 🎬 **演示效果** | **10%** | 演示流畅性、表达清晰度 |

> 每位评委独立打分，最终成绩取加权平均值。评审过程全程保密，结果将在颁奖典礼公布。

### 5.2 人气奖评选

- 通过**公开投票**产生，面向社会开放
- 每位用户每日可投 **3 票**
- 投票截止日期与作品提交截止日期一致
- **严禁刷票**，一经发现取消资格
- 人气奖可与专业评审奖项**叠加获得**
