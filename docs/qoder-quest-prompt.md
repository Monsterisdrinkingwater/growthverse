## 提示词正文（从这里开始复制）

创建一个名为 "GrowthVerse 成长宇宙" 的 Web 应用。这是一个以读书为核心驱动的 AI 成长操作系统 — 用户从一本书出发，通过作者/时代/主题的关联无限展开探索网络，AI 实时整合小红书和B站等社交平台的真实读者声音，最终把探索旅程总结为完整的知识脉络。

---

## 技术栈

- Next.js 15 (App Router) + React 19 + TypeScript
- Tailwind CSS 4 + shadcn/ui 组件库
- Supabase (PostgreSQL) 用于数据库和认证

- Framer Motion 用于动画和交互效果
- Zustand 用于状态管理

## 外部数据源

### 1. Google Books API（图书元数据，免费无需认证）
- 搜索: GET https://www.googleapis.com/books/v1/volumes?q=关键词
- 返回: 书名、作者、出版社、简介、封面图、评分、分类
- 封装为 Agent 工具: search_books, get_book_details

### 2. 微信读书 Skill API（用户阅读数据，官方接口）
- 安装: npx skills add Tencent/WeChatReading -g
- 能力: 书架访问、阅读统计、笔记划线、图书搜索、个性化推荐
- 用户扫码授权后获取 wrk-... API Key
- 封装为 Agent 工具: get_reading_history, get_reading_stats, get_recommendations

### 3. Rnote API（小红书数据，第三方接口）
- 网站: rnote.dev，按调用计费，注册有免费额度
- 能力: 按关键词搜索笔记、获取笔记详情和评论
- 搜索示例: 搜索"非暴力沟通 书评"获取小红书上的读者分享
- 封装为 Agent 工具: get_social_reviews
- 注意: 始终展示原文链接，引导用户回到小红书查看完整内容

### 4. B站 API（视频评论数据，开源库）
- 库: bilibili-api-python（pip install bilibili-api-python）
- 能力: 搜索视频、获取评论和弹幕
- 封装为 Agent 工具: get_video_discussions

## AI Agent 架构

### Agent 阵容
- **Core（编排器）**: 意图路由 + 上下文管理 + 工具调用编排
- **Atlas（读书教练）**: 图书推荐、阅读规划、书单定制，结合用户阅读历史+成长目标+社交热度
- **Pulse（社交阅读）**: 小红书/B站书评聚合、读者声音分析
- **Echo（反思伙伴）**: 读后反思引导、洞察提取、成长关联
- **Prism（成长洞察）**: 跨维度数据聚合、阅读成长叙事生成

### 核心对话流程
用户输入 → Core 识别意图 → 并行调用工具:
1. get_reading_history() 了解用户阅读背景
2. search_books(query) 获取图书元数据
3. get_social_reviews(query) 获取小红书书评
4. get_video_discussions(query) 获取B站评论
→ AI 综合所有数据生成个性化回复
→ 回复中包含: 图书推荐卡片 + 社交讨论摘要 + 可点击链接

## 核心功能模块

### 模块一: 用户系统 + 微信读书连接
- 邮箱/GitHub OAuth 注册登录
- 微信读书扫码授权连接
- AI 分析阅读历史，生成用户阅读画像
- Onboarding 对话: "基于你的23本书，你在自我认知和职业发展最强。让我们开始你的阅读探索之旅。"

### 模块二: AI 读书对话
- 对话式交互界面，流式响应 + 打字动画
- 显示当前是哪个 Agent 在响应（头像 + 名字 + 思考动画）
- 对话中实时展示图书推荐卡片、小红书笔记摘要、B站评论精选
- Agent 之间可以协作切换（对话中显示切换动画）

### 模块三: 图书宇宙探索（最核心的互动页面！）

这是整个产品最有趣的交互体验。从一本书出发，通过关联无限展开探索网络。小说和非小说类图书都适用。

#### 图书卡片交互
- 图书以精美的卡片形式展示（封面 + 书名 + 作者 + 一句话描述）
- 卡片有微妙的悬浮/翻转动画效果（Framer Motion）
- 点击卡片 → 进入图书深度探索页（带翻页/展开过渡动画）

#### 图书深度探索页（打开一本书后看到的内容）

顶部区域:
- 大封面 + 书名 + 作者名
- 作者头像/照片
- 评分 + 社交平台讨论热度
- 一句话 AI 推荐语

作者区域:
- 作者照片 + 简介 + 时代背景
- "同作者的其他作品" — 横向滚动的图书卡片
- 点击任意一本 → 打开同样的深度探索页（递归交互！）

背景知识区域:
- AI 生成的时代背景介绍（如"19世纪俄国文学"、"2020年代中国科幻"）
- 关键概念/术语解释
- 相关历史事件或文化背景

关联作品区域（三个维度展开）:
- ① 同作者作品: 该作者的其他著作
- ② 同时代作品: 同一时期其他作者的代表作
- ③ 同主题作品: 相同主题/类型的跨时代作品
- 每个维度都是横向滚动的图书卡片
- 点击任意一本 → 打开同样的深度探索页（无限递归！）

社交声音区域:
- 小红书读者对这本书的讨论精选
- B站书评视频评论精选
- 可点击链接回到原始平台

#### 探索路径追踪
- 用户每次点击一本书、一个作者、一个关联，系统都记录在"探索路径"中
- 页面底部显示一个小型的"探索轨迹"可视化（类似面包屑但是可视化的路径图）
- 用户可以看到自己从最初的A书，经过B、C、D，最终到达E书的完整路径
- 路径图可以展开为全屏的"探索地图"

#### 探索旅程总结（AI 生成）
- 用户探索了一系列书之后，点击"生成小结"按钮
- AI 分析用户浏览过的所有书，生成一份知识小结:
  - "你从《三体》出发，探索了刘慈欣的其他作品，然后延伸到黄金时代科幻（阿西莫夫、克拉克），又跳转到同主题的社会学读物，最后到达了中国当代科幻新生代作品。"
  - 包含一个知识脉络图（哪些书通过什么关联连接在一起）
  - AI 给出"下一步推荐"
  - 关联到小红书/B站上的相关讨论
- 小结可以保存，形成用户的"阅读探索档案"
- 用户可以从小结重新进入任意一本书继续探索

#### 递归交互的技术实现
- 每次打开书的深度探索页，调用 Google Books API 获取:
  - 图书详情 (get_book_details)
  - 同作者作品 (search_books: author:"作者名")
  - 同主题作品 (search_books: subject:"分类标签")
  - 同时代作品 (search_books: publish_date:时代范围 + subject)
- 数据缓存在前端（Zustand store），避免重复请求
- 探索路径存储在本地数据库，用于生成小结
- 社交数据按需加载（用户滚动到社交区域时才调用 API）

### 模块四: AI 助手侧边栏（与图书宇宙探索联动）

#### 布局
- 图书宇宙探索页面采用左右分栏布局
- 左侧（60-70%宽度）: 图书深度探索主区域
- 右侧（30-40%宽度）: AI 助手对话面板（可折叠/展开）
- 移动端: 右侧面板变为底部抽屉或浮动按钮

#### AI 助手能力
- 始终在线的对话式 AI 助手，了解用户当前正在探索的图书上下文
- 用户可以随时向 AI 提问:
  - "这本书讲了什么？"
  - "有没有类似的书推荐？"
  - "小红书上大家怎么评价这本书？"
  - "帮我总结一下我刚才看的这些书"
- AI 的回答自动结合用户当前的探索路径

#### 智能书卡片弹出（核心交互！）
- 当 AI 回复中提到任何书名、作者名时 → 自动在对话中生成一张迷你书卡片
- 当用户自己在输入中提到已知书名时 → 也弹出对应的书卡片
- 书卡片样式: 小型书籍造型（迷你封面 + 书名 + 作者 + 评分），像一本小书立在对话流中
- 卡片有微妙的呼吸/发光动画吸引注意
- 用户可以选择:
  - 点击卡片 → 在主区域（左侧）打开这本书的深度探索页
  - 忽略 → 卡片安静地留在对话记录中
  - 长按/右键 → "加入探索路径" / "稍后再看"
- 每次对话中最多同时显示 3-5 张书卡片，避免信息过载

#### 联动效果
- 用户在左侧打开一本新书 → 右侧 AI 自动说:
  "我看到你在看《XXX》，小红书上 287 位读者讨论了这本书的... 要不要看看同主题的《YYY》？" → 对话中弹出《YYY》的小书卡片
- 用户在右侧问 AI 推荐 → AI 推荐的书卡片点击后直接在左侧展开深度探索页
- 左右两侧形成无缝的"对话 ↔ 探索"循环

#### 技术实现
- AI 回复经过后处理: 用 NLP/正则识别书名和作者名实体
- 识别到的实体 → 调用 search_books API 获取图书元数据
- 生成内嵌书卡片组件（BookMention component）
- 书卡片数据缓存在前端，避免重复请求
- 左右面板通过共享 Zustand store 同步状态:
  - 左侧打开新书 → 触发右侧 AI 主动发言
  - 右侧点击书卡片 → 触发左侧导航到对应书的探索页

### 模块五: 社交阅读脉搏
- 按图书/主题浏览社交平台讨论
- 小红书笔记瀑布流（图片 + 标题 + 摘要 + 互动数据）
- B站视频列表（缩略图 + 标题 + 评论数 + 播放量）
- AI 总结: "关于《被讨厌的勇气》，小红书读者最讨论'课题分离'概念，B站读者更关注'共同体感觉'"

### 模块六: 读后反思引擎
- 读完一本书后，AI 引导结构化反思:
  - "这本书最触动你的一个观点是什么？"
  - "你会如何把这个洞察应用到生活中？"
  - "这本书和你之前读的《XX》有什么关联？"
- 反思结果关联到成长维度（自我认知/情商/职业/关系/健康/哲学）
- AI 基于反思推荐下一本书

### 模块七: 互动页面

#### 阅读成长地图
- 游戏化冒险地图界面
- 用户的阅读路径渲染为手绘风格的冒险地图
- 每个成长维度是一条路径（"心理之路"/"商业之路"/"科技之路"等）
- 每本书是地图上的一个"探索地标"
- 未探索区域有迷雾效果，随阅读逐渐揭开

#### 每日读书盲盒
- 每天打开 App 可以拆一个"成长盲盒"
- 内容随机: 一句书摘 / 一个今日阅读挑战 / 一本惊喜推荐书 / 一个反思问题
- 拆盒动画效果（Framer Motion: 盒子摇晃 → 打开 → 内容飞出）

#### 阅读性格测验
- 有趣的互动式小测验（10-15个问题）
- 分析用户的阅读性格类型（如"深度思考者"/"跨界探索者"/"实践行动派"）
- 结果可以生成精美分享卡片（适配小红书尺寸）

1. 图书宇宙探索是核心亮点！递归交互必须流畅，每次打开书都有"发现新世界"的感觉

3. 社交数据（小红书/B站）要展示原文链接，引导用户回到原平台
4. 探索旅程总结是差异化功能 — 把零散的浏览变成完整的知识脉络
5. 小说和非小说类图书都适用同样的探索体验
6. Terrace 暖调设计风格贯穿全站
7. 所有页面响应式适配
8. 先做核心对话 + 图书探索，再做社交数据和互动页面
